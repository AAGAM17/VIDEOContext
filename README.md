# VideoContext

**The open-source semantic layer for video.**

Turn video into timestamped, searchable context for AI agents and applications.

```
                    Video
                      │
        ┌─────────────┼─────────────┐
      ASR            OCR       Vision · Events
        └─────────────┼─────────────┘
                      │
          Temporal Semantic Index
                      │
              LLMs · Agents · RAG
```

`pip install videocontent` · [Architecture](docs/ARCHITECTURE.md) ·
[`.vctx` format](docs/VIDEO_CONTEXT_SPEC.md) · [Roadmap](docs/ROADMAP.md)

</div>

---

Modern models can look at video. What is missing is the **infrastructure layer** underneath:
something that ingests a file, extracts speech, on-screen text, scenes and events, keeps
every fact anchored to a timestamp, and hands an LLM exactly the moments that matter — with
evidence.

That is VideoContext. It is not a wrapper around one vision API; it is the layer that makes
video as indexable as text.

```python
from videocontent import Video

video = Video("demo.mp4")
video.process()                      # ASR + OCR + scenes + events → demo.vctx

for hit in video.search("pricing"):
    print(hit.timecode, hit.modalities, hit.text[:60])
```

```
00:20 → 00:29  ['ocr', 'transcript']  Pricing  Plan Seats Price / month  Starter 3 $29 …
00:29 → 00:38  ['ocr', 'transcript']  Competitor pricing  Competitor A charges $2 per hour …
```

Every result is a real span of the real video. Timestamps are copied from evidence, never
generated by a model — so a returned time always points at something that actually happened.

---

## Why it exists

| Without VideoContext | With VideoContext |
|---|---|
| Upload the whole video to a model on every question | Process once, query forever |
| Answers with no way to check them | Answers with timestamped evidence per modality |
| Locked to one provider's video API | Provider-agnostic adapters; local models work |
| Speech *or* on-screen text | Speech **and** on-screen text **and** scenes **and** events, fused on one timeline |
| Costs scale with every query | Costs scale with processing, which is cached and deduplicated |

## Install

```bash
pip install videocontent           # core: probe · sampling · scenes · OCR · retrieval
pip install "videocontent[asr]"    # + faster-whisper speech-to-text
pip install "videocontent[all]"    # + vision adapters and the REST API
```

Requirements: **Python ≥ 3.10** and **FFmpeg** on `PATH`
(`brew install ffmpeg` · `apt install ffmpeg`). For on-screen text, install Tesseract
(`brew install tesseract` · `apt install tesseract-ocr`).

Check your machine at any time:

```bash
videocontent doctor
```

Nothing here needs an account, an API key, or a GPU.

## Quickstart

### CLI

```bash
videocontent process demo.mp4            # → demo.vctx
videocontent inspect demo.vctx           # transcript · OCR · scenes · events · timeline
videocontent search demo.vctx "pricing"  # ranked spans with evidence
videocontent benchmark demo.mp4          # per-stage timings and cost estimate
```

### Python

```python
from videocontent import Video

video = Video("lecture.mp4")
video.process(ocr=True, transcription=True)

doc = video.document                      # a fully typed .vctx document
print(doc.video.duration, len(doc.segments), len(doc.events))

# What was on screen at 3:21?
snapshot = doc.at(201.0)
print([o.text for o in snapshot["ocr"]])

# Where was a phrase said or shown?
for hit in video.search("competitor", modalities=["transcript", "ocr"], top_k=5):
    print(hit.timecode, hit.reason)
```

## What comes out

A `.vctx` document: one JSON file, versioned and vendor-neutral, holding everything the
pipeline learned. Full specification in [docs/VIDEO_CONTEXT_SPEC.md](docs/VIDEO_CONTEXT_SPEC.md).

```jsonc
{
  "vctx_version": "1.0",
  "video":  { "duration": 62.4, "fps": 30.0, "width": 1280, "height": 720 },
  "stages": [ { "name": "ocr", "status": "ok", "provider": "tesseract", "remote": false } ],

  "transcript": [
    { "start": 14.9, "end": 20.4, "text": "Revenue reached forty two lakh rupees…" }
  ],

  // On-screen text is temporally deduplicated: one fact with a lifespan,
  // not the same string repeated across 40 000 frames.
  "ocr": [
    { "start": 14.0, "end": 20.9, "text": "Revenue Rs 42L", "frame_count": 7, "stable": true }
  ],

  "events": [
    { "type": "slide_changed", "start": 20.9, "end": 21.0, "source": ["ocr", "visual"] }
  ],

  "segments": [ { "start": 14.0, "end": 21.0, "transcript_ids": ["utt_0002"], "ocr_ids": ["ocr_0011"] } ]
}
```

Two properties make this more than a dump:

- **`stages` records what ran.** An empty `ocr` array with `status: "ok"` means the video has
  no on-screen text; `status: "skipped"` means nobody looked. Absence is never ambiguous.
- **`remote` records what left the machine.** You can audit whether a video was ever sent to
  a third party by reading the artifact itself.

## Design principles

1. **Model agnostic** — the core imports no provider SDK; ASR, OCR, vision, embeddings, vector
   stores and LLMs are all adapters resolved by name.
2. **Local first** — the default path runs offline. Cloud providers are accelerators you opt
   into, per stage.
3. **Timestamp precise** — every fact carries `start`/`end` on the media clock.
4. **Evidence first** — search and Q&A return the spans and modalities that justify them.
5. **Incremental** — stages are independent; a vision failure cannot invalidate your transcript.
6. **Cost efficient** — adaptive sampling, frame dedup, temporal OCR dedup, content-hash caching.

Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for how these are enforced rather than aspired to.

## Configuration

Sensible defaults, overridable from four places (later wins): `config.yaml` → environment →
Python → CLI flags.

```bash
VIDEO_CONTEXT_ASR_PROVIDER=faster-whisper
VIDEO_CONTEXT_ASR_MODEL=base
VIDEO_CONTEXT_OCR_PROVIDER=tesseract
VIDEO_CONTEXT_SAMPLING_MODE=adaptive
VIDEO_CONTEXT_VISION_PROVIDER=null        # nothing leaves your machine
```

```python
from videocontent import Video, ProcessingConfig

config = ProcessingConfig()
config.sampling.mode = "adaptive"
config.sampling.max_fps = 6
config.ocr.languages = ["eng", "hin"]

Video("lecture.mp4", config=config).process()
```

## Project status

V0.1 — the vertical slice — is what exists today: ingestion, adaptive sampling, scene
detection, Whisper ASR, Tesseract OCR with temporal deduplication, rule-based events,
segmentation, the `.vctx` format, hybrid lexical retrieval, the SDK and the CLI.

Vision providers, embeddings, `ask()`, the REST API, the MCP server and the web explorer are
designed with seams already in place; see [docs/ROADMAP.md](docs/ROADMAP.md) for the order.

Benchmark claims will appear here only when they are reproducible from
`benchmarks/`. Until then this README describes what the code does, not what it might.
